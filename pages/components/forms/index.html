Forms

Form groups with icons, validation, selects, dates, files, and checkboxes.

Preview

Enter a valid email address

Usage

  • .form-group
  • .form-group-input-wrapper
  • .form-control
  • .form-error
  • .is-invalid
  • .icon-right
  • .air-datepicker-field
  • .form-check / .form-check-input / .form-check-label

Agent instruction

  • User fields use Lucide user, not user-round.
  • Selects need a right chevron-down with class icon-right.
  • Date fields use .air-datepicker-field (and Air Datepicker assets when the page needs them).
  • Validation errors use .form-error with circle-x, plus aria-invalid and aria-describedby.
  • Do not invent alternate form class names when .form-group already covers the pattern.
