Agent instruction

  • Completed or confirm step markers use Lucide check, not check-circle-2.
  • Back uses arrow-left. Next uses arrow-right. Do not substitute move-left / move-right.
  • Keep data-step values aligned between .step-item and .base-stepper-panel.
  • Hide inactive panels with the hidden attribute; do not invent alternate show/hide classes.
