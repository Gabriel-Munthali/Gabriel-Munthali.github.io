Agent instruction

  • Use .table-toolbar for search and filters above the table; do not invent a separate filter bar layout.
  • Status cells use project badges with iconology status icons (check-circle-2, clock, hourglass, etc.).
  • Manage actions use settings-2. Delete menu items use trash.
  • Pagination uses chevron-left / chevron-right with project .button classes on page links.
  • Date range chips use .air-datepicker-range-field when a custom range is needed.
