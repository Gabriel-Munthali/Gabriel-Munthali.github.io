Modals

Bootstrap modals and offcanvas panels with brand header, footer, and form patterns.

Preview

Usage

  • .modal / .modal-dialog / .modal-content
  • .modal-dialog-centered
  • .modal-size-sm / .modal-xl
  • .modal-header / .modal-body / .modal-footer
  • .modal-icon / .modal-icon--success
  • .offcanvas / .offcanvas-end
  • .offcanvas-header / .offcanvas-body / .offcanvas-footer

Agent instruction

  • Use Bootstrap modal and offcanvas markup and JS. Do not build custom overlays.
  • Footer actions use project .button classes, not Bootstrap .btn.
  • Confirm icons in modal headers use check inside a success .modal-icon. Close uses x.
  • Prefer offcanvas for forms and side detail; prefer modals for short confirmations.
  • Always set aria-labelledby and a matching title id.
